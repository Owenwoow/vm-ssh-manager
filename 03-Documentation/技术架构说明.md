# VM SSH Manager 技术架构说明

## 1. 分层

- `core/key_manager.py`：密钥生成、加载、公私钥匹配和指纹。
- `core/ssh_client.py`：Paramiko SSH、首次主机指纹确认和命令执行。
- `core/public_key_deployer.py`：幂等追加/精确撤销 `authorized_keys` 条目。
- `core/sudo_manager.py`：独立 sudoers 文件、备份、visudo 校验、安装与回滚。
- `core/config_manager.py`：保留原有内容的 OpenSSH Config Host 块维护。
- `core/connection_tester.py`：Paramiko 公钥认证和 Windows `ssh -G` 解析测试。
- `core/task_manager.py`：初始化流程编排和逐步报告。
- `core/registry.py`：只保存 VM 元数据，不保存密码。
- `cli/` 与 `gui/`：分别调用同一套 core。

## 2. 运行时依赖

Python 3.11+；Paramiko 3.5+；GUI 使用 PySide6。发布 EXE 使用 PyInstaller。最终 Windows 版本需在 Windows x64 环境构建。

## 3. 远程流程

密码认证 → 首次主机密钥确认 → 读取 `$HOME` → 安全创建/校验 `.ssh` → 幂等追加公钥 → 可选 sudoers 配置 → 本地 SSH Config 更新 → Paramiko 公钥认证 → 原生 `ssh -G` 检查。

## 4. 配置位置

- SSH：`%USERPROFILE%\.ssh\config`、`known_hosts`、`id_ed25519_vm`。
- VM 元数据：`%APPDATA%\VM SSH Manager\vms.json`。
- VM 元数据不含任何密码或私钥内容。
