# VM SSH Manager 配置说明

| 配置项 | 默认值 | 说明 |
|---|---|---|
| 默认密钥 | `%USERPROFILE%\.ssh\id_ed25519_vm` | Ed25519，允许复用 |
| SSH 端口 | 22 | 可自定义 |
| SSH Config | `%USERPROFILE%\.ssh\config` | 只更新目标 Host 块 |
| known_hosts | `%USERPROFILE%\.ssh\known_hosts` | 保存首次确认的主机指纹 |
| VM 登记 | `%APPDATA%\VM SSH Manager\vms.json` | 只保存连接元数据 |
| sudoers | `/etc/sudoers.d/<username>` | 普通用户可选项 |

SSH Config 写入的管理项：`HostName`、`User`、`Port`、`IdentityFile`、`IdentitiesOnly`、`ServerAliveInterval`、`ServerAliveCountMax`。
